# HireSense — AI Resume Analyzer

**Live site:** https://viju03-tech.github.io/hiresense/

Upload a resume and get a real, explainable analysis — no server, no uploads, everything runs in your browser.

## What it does

- **Resume analysis** — upload a PDF or DOCX resume (or paste the text) and get a skill match score, matched vs. missing skills, and a skill-by-category breakdown
- **Jobs you can apply for** — 32 tech + non-tech roles ranked by match %, with required skills shown as have vs. missing, best match highlighted. No job description needed.
- **Job description matching** — paste any job description (optional) for a match score and semantic similarity
- **ATS score** — 0–100 with a 13-point breakdown and fixes for each failing check
- **Salary estimate** — rough India-market range per role, labelled as an estimate
- **Experience level** — Fresher / Junior / Mid-level / Senior, detected from the resume
- **Skill-gap learning plan** — steps and free resource links for missing skills
- **Job links** — real LinkedIn / Indeed / Naukri searches per role, with Chennai / Bangalore / Remote filters
- **Resume builder** — auto-fixes headings, bullets and duplicates, download an improved PDF
- **Compare** — score two resumes side by side
- **Dashboard** — analysis history, saved/shortlisted jobs, PDF/CSV reports

## Skills & jobs covered

199 skills across 18 categories, 32 roles — Data Scientist, Machine Learning Engineer, AI Engineer, Data Analyst, Backend / Frontend / Full Stack Developer, DevOps, Cloud, Cybersecurity, UI/UX Designer, Digital Marketing, Content Writer, HR / Recruiter, Accountant, Sales, Customer Support, Business Analyst, Operations, Logistics, Teacher / Trainer, Nurse / Healthcare, Event Manager, and more.

## How to use

Open https://viju03-tech.github.io/hiresense/, upload your resume, and see your results. No account needed — history is saved in your browser only.

## Tech

Single-file static website (`index.html`) — HTML, CSS, JavaScript, PDF.js + Mammoth for in-browser resume parsing. Hosted on GitHub Pages.
